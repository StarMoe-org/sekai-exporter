# 剧本

[English](scenario.md)

`scenario` 形式是剧情的场景数据——其台词、布局、效果、声音以及它所引用的资源——写成 JSON 文档。转换器：`sekai-moesekai` 中的 `scenario`（feature `scenario`）。形式版本：1。

## 1. 运行时

网页上的剧情阅读器与播放器，以及搜索、翻译或分析剧情的工具。形式按游戏的存储给出场景数据；它不把所含的名称解析为文件，不播放剧情，也不把它与列出各话的游戏数据表连接。

## 2. 内容

一个成员：

| 角色 | 内容 |
|---|---|
| `scenario` | JSON 文档，扩展名 `json` |

文档是一个对象，按存储顺序保存场景数据对象的每个序列化字段，但排除每个 `MonoBehaviour` 都有的四个字段：`m_GameObject`、`m_Enabled`、`m_Script` 与 `m_Name`（名称重复了 `ScenarioId`）。字段名按存储原样写出，例如 `ScenarioId`、`AppearCharacters`、`Snippets`、`TalkData`、`LayoutData`、`SpecialEffectData`、`SoundData` 与 `NeedBundleNames`。

值的写法如下：

| 所存的值 | JSON |
|---|---|
| 结构 | 对象，字段按存储顺序排列 |
| 数组 | 数组 |
| 布尔值 | `true` 或 `false` |
| 整数 | 数，全为数字 |
| 浮点数 | 数：该值为 32 位浮点数时，为能读回同一 32 位浮点数的最短十进制形式，否则为能读回同一 64 位浮点数的最短十进制形式 |
| 字符串 | 字符串；`"`、`\` 与控制字符转义，其他每个字符按其在 UTF-8 中的原样写出 |

文档在字符串之外没有空白。剧情所用的资源在文档中以游戏所存的字符串指明——资源包名称、语音 ID、背景与音乐名称——并不包含在文档中。

## 3. 来源

**根对象：** 脚本为 `Assembly-CSharp/Sekai.ScenarioSceneData` 的每个 `MonoBehaviour`（类 114）。形式不读取游戏数据表。

**读取的字段：** 根对象的全部序列化字段。

**文档以外的结果：**

| 情况 | 结果 |
|---|---|
| 某个字段含有引用、映射、字节数组，或不是 UTF-8 的字符串 | 错误 `unsupported` |
| 某个浮点数字段不是有限数 | 错误 `malformed` |

## 4. 容器

成员是成品字节，即第 2 节所述的 UTF-8 JSON 文件。没有编码参数。

## 5. 正确性

文档不加解释地保存对象的所存值，因此就游戏所读的内容而言它是完整的，且同一对象总是给出相同的字节：字段顺序即存储顺序，每个数只有一种写法。在真实资源包上，用每份文档的每个值与 UnityPy 经其 type tree 从同一对象读取的字段比对（浮点数按 32 位浮点数），并把全部文档在单线程与多线程下各转换一次、比较字节，来检查。

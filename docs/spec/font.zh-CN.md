# 字体

[English](font.md)

`font` 形式是 `Font` 对象所存储的字体文件。转换器：`sekai-convert` 中的 `font`（feature `text`）。形式版本：1。

## 1. 运行时

任何用字体文件渲染文本的程序：操作系统、通过 `@font-face` 的浏览器，以及字体工具。

## 2. 内容

一个成员：

| 角色 | 内容 |
|---|---|
| `font` | `m_FontData` 的字节，不作改动 |

扩展名按数据的前四个字节确定：

| 签名 | 扩展名 |
|---|---|
| `00 01 00 00` 或 `true`（TrueType 轮廓） | `ttf` |
| `OTTO`（CFF 轮廓） | `otf` |

## 3. 来源

**根对象：** 每个 `Font`（类 128）。形式不读取游戏数据表。

**读取的字段：** `m_FontData`。

**文件以外的结果：**

| 情况 | 结果 |
|---|---|
| `m_FontData` 为空 | 无资产。该字体指向设备上已安装的字体，不存储文件 |
| 签名不在第 2 节的表中 | 错误 `unsupported` |
| `m_FontData` 缺失或不是字节数组 | 错误 `malformed` |

## 4. 容器

成员是成品字节，按原样写出：一个 OpenType 文件，带 TrueType 或 CFF 轮廓。没有编码参数。

## 5. 正确性

成员即所存的 `m_FontData`，因此就是 Unity 导入的字体文件。在真实资源包上，用每个成员的 SHA-256 及其扩展名与 UnityPy 为同一对象读取的字体数据比对来检查。

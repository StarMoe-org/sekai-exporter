# 发布

[English](publishing.md)

发布为[派生图](architecture.zh-CN.md)的结果赋予名称，并将其放置于使用者读取的位置。核心产出以内容寻址的结果；结果如何组织、存放于何处，属于一个独立且可替换的层。

## 单一 store

系统中只有一个 **store**：以内容寻址存放字节之处，可以是本地目录，也可以是 S3 兼容存储中的一个前缀。结果只写入一次。

- store 中的对象以 `<aa>/<sha256>.<扩展名>` 命名。与 Git 仓库中的对象相同，这一名称不承载含义；含义由指向该对象的索引与资产文档承载。
- store 的本地副本是一个容量有限的缓存。增量判断、缓存命中与发布差异只需要哈希，而哈希保存在目录中。只有当某个视图须产出不同的字节，或首次向一个新目标发布时，才需要再次读取字节。

## 语义随输出发布

- **资产文档。** 每个资产随附一份文档 `<逻辑路径>.asset.json`，该文档本身也是 store 中的对象。文档记录资产形式、转换器名称与版本、以 `(资源包, path ID, 类)` 表示的来源对象、成员文件及每个文件的角色（例如某个材质的底色贴图，或某个音频对象的第三个 cue），以及该资产所引用的其他资产。
- **索引条目携带语义。** 索引分片的每个条目给出文件的名称、哈希、大小、媒体类型、所属资产及其角色，而不仅是名称与哈希。
- **对象文档**（`<资源包>/_objects.json`）随每个资源包发布，给出每个对象的类、字段与已解析的引用。

因此，任何持有 store、索引与资产文档的人，都能查明每个文件是什么、来自何处，以及它与其他文件的关系。目录是这些信息的索引，可由其重建。

## 布局

| 布局 | 形状 | 重复 | 使用者的读取方式 |
|---|---|---|---|
| `index` | store 本身，加上每个区服、每个视图的一份路径索引：按目录划分的小型 JSON 分片，将每个名称映射到其哈希、大小、类型、所属资产与角色 | 无 | 先查索引，再取对象。Rust 工作区之外提供一个带缓存的小型 TypeScript 解析函数 |
| `tree` | 每个区服、每个视图一棵路径树 | 后端不支持链接时，出现在多个区服中的字节在每棵树中各存一份 | 按路径读取 |

`index` 布局直接引用 store，不复制任何内容。`tree` 布局在本地文件系统及支持链接的后端上使用硬链接，在普通 S3 上使用服务端复制。

每种资产形式另有一份**列表**，给出某区服某版本中该形式全部资产的逻辑路径、资产形式、指纹与大小。使用者以列表取代为单个查看器专门构建的索引。

## storage 视图

`storage` 视图还原 Moesekai 网站及其他读取方所使用的资源存储站的路径树，路径、文件名与编码参数均保持一致。共享同一逻辑路径的资产使用[架构](architecture.zh-CN.md)中定义的名称。它以 `tree` 布局物化于固定的公开路径上，无法原子切换，因此按以下顺序写入：

1. 写入全部新文件；
2. 写入新版本的列表；
3. 新版本不再包含的文件，延后一个发布周期删除，使读取上一版本的读者得以完成读取。

由此得到的一致性有如下界限：每个文件的替换是原子的；在写入一个版本期间，读者可能同时看到上一版本与新版本的文件；中断后再次运行发布，结果收敛到新版本；资产存在错误的文件保留其原有字节，直至转换成功。

## 发布协议

1. 只有在本次运行没有运行失败（下载失败、写入失败或进程崩溃）时，版本才会被发布。资产错误不妨碍发布，并随版本一并列出。
2. 索引分片不可变，以其 SHA-256 命名。
3. 一次发布的修订号是其排序后记录的哈希，与 JSON 的书写格式无关。
4. 推进某个版本的指针之前，核验该发布所引用的每个对象均以所记录的哈希存在于 store 中。
5. 失败以失败阶段的名称报告。失败的阶段不改变原有指针。
6. 一次发布面向多个目标时，各目标的指针并非原子地一同推进。每个目标保留其最近一次完整的指针，再次运行发布即可补齐其余目标。

## 求值与发布的组合

| 部署形态 | 求值 | 地点 | 布局 |
|---|---|---|---|
| 完整的静态镜像 | 急切 | 批处理 | `index`，storage 视图另用 `tree` |
| 存储有限的自托管 | 绑定急切，转换惰性 | 服务 | `index`，store 作为可淘汰的缓存 |
| 无服务器 | 绑定急切，转换惰性 | 运行 WebAssembly 核心的函数：查找绑定、获取资源包、转换、缓存、返回 | `index` |
| 只持有自有文件的使用者 | 惰性 | 浏览器：WebAssembly 核心在本地解包并转换拖入的资源包，无需服务器 | 无 |
| 其他程序 | 任意 | 库 | 由该程序决定 |

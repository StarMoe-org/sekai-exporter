# Storage tree comparison

[中文](README.zh-CN.md)

These scripts compare two directory trees, and compare two output directories of the same input
byte for byte. They use only the Python standard library. Pillow and ffprobe are optional.

## compare.py

```bash
python compare.py A B [--known known.tsv] [--ffprobe PATH] [--report out.json]
```

`A` is the tree under test and `B` is the reference tree. Every relative path (forward slashes,
sorted) is classified as:

- `missing`: the path exists only in B.
- `extra`: the path exists only in A.
- `same`: the contents are judged equal.
- `different`: the contents are judged different.

The judgement depends on the file type:

- `.json`: both files are parsed and the values are compared. Object key order is ignored, and
  numbers compare as parsed values, so `1` equals `1.0`. A boolean never equals a number. The
  first differing path is reported, for example `$.a[3].b`.
- `.png`, `.webp`, `.jpg`: equal bytes are `same`. Otherwise, with Pillow, both images are decoded
  to RGBA and compared pixel by pixel. A size mismatch or the number of differing pixels is
  reported. Without Pillow, only the format and the width and height from the file header are
  compared, and images whose bytes differ are `different`, with a note that the pixels were not
  compared.
- `.mp3`, `.m4a`, `.aac`, `.mp4`, `.ogg`: equal bytes are `same`. Otherwise `ffprobe -v error
  -show_streams -show_format -of json` runs on both files, and the format contract is compared:
  container format name; codec, sample rate, channels, width and height of each stream in order;
  duration; and the bit rate in tiers of 32 kb/s (rounded to the nearest tier).
  The duration may differ by one frame of the reference tree's streams: `1 / frame rate` for
  video, `1024 / sample rate` for AAC audio, `1152 / sample rate` for MP3 audio, and 0.05 s
  otherwise. The first differing field is reported.
- Everything else: SHA-256 comparison.

`--ffprobe` names the ffprobe executable. A command whose name ends in `.py` runs with the
current Python interpreter. By default `ffprobe` is looked up on `PATH`. Without ffprobe, a
differing media file is reported as `different`.

The output lists the counts per category, then the non-matching paths grouped by category and by
top-level directory. Files at the top level are grouped under `(top level)`. `--report` writes
the same grouping as JSON.

The exit status is 0 when every missing, extra or different path is explained by the known
differences, 1 when any is not, and 2 for usage errors.

## Known differences

`--known` reads a hand-maintained TSV file with one `pattern<TAB>reason` pair per line:

```text
# lines starting with a hash are comments
logs/*.txt	timestamps are written at run time
legacy/old-name.bin	kept for a compatibility check
```

The pattern is an `fnmatch` glob matched case-sensitively against the relative path. A missing,
extra or different path that matches a pattern is reported under that reason and does not fail
the run. Paths whose contents are the same are never matched. Blank lines are skipped.

## determinism.py

```bash
python determinism.py RUN1 RUN2 [--metrics FILE]
```

Every file of `RUN1` must exist in `RUN2` with the same bytes, and the reverse. The script lists
missing and differing paths. With `--metrics`, `FILE` is a JSON Lines file with one object per
line, normally the `metrics.jsonl` of the second run. Each span of the `convert` stage
(`{"kind": "span", "stage": "convert"}`) is one recomputed derivation, and the count must be 0. The exit status is 0 when everything matches, 1 otherwise, and 2 for usage errors.

## Tests

From the repository root:

```bash
python -B -m unittest discover -s tools/compare-storage -v
```

The tests build all trees in temporary directories from generated bytes. The media tests use a
fake ffprobe script, so no real ffprobe is needed. Tests that need Pillow are skipped when it is
not installed.
